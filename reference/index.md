# Package index

## Theme

Create and update a Liquid Glass theme for your Shiny app.

- [`glass_theme()`](https://ericrayanderson.github.io/shinyglass/reference/glass_theme.md)
  : Liquid Glass theme for 'shiny'

- [`update_glass_theme()`](https://ericrayanderson.github.io/shinyglass/reference/update_glass_theme.md)
  : Update glass theme options in a running app

- [`glass_theme_toggle()`](https://ericrayanderson.github.io/shinyglass/reference/glass_theme_toggle.md)
  : Light / dark / auto theme toggle buttons

- [`observe_glass_theme_toggle()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_theme_toggle.md)
  :

  Observe
  [`glass_theme_toggle()`](https://ericrayanderson.github.io/shinyglass/reference/glass_theme_toggle.md)
  buttons on the server

- [`glass_intensity_slider()`](https://ericrayanderson.github.io/shinyglass/reference/glass_intensity_slider.md)
  : Liquid Glass intensity slider (iOS 27-style)

- [`observe_glass_intensity()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_intensity.md)
  :

  Keep session intensity in sync with
  [`glass_intensity_slider()`](https://ericrayanderson.github.io/shinyglass/reference/glass_intensity_slider.md)

- [`glass_preset_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_preset_input.md)
  : Light / dark / auto preset select input

- [`observe_glass_preset_input()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_preset_input.md)
  :

  Observe
  [`glass_preset_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_preset_input.md)
  on the server

- [`glass_resolved_preset()`](https://ericrayanderson.github.io/shinyglass/reference/glass_resolved_preset.md)
  : Resolved light or dark appearance

- [`glass_accent_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_accent_input.md)
  : Accent color wells

- [`observe_glass_accent()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_accent.md)
  :

  Keep session accent in sync with
  [`glass_accent_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_accent_input.md)

- [`glass_system_colors()`](https://ericrayanderson.github.io/shinyglass/reference/glass_system_colors.md)
  : iOS system accent colors

- [`glass_page()`](https://ericrayanderson.github.io/shinyglass/reference/glass_page.md)
  : One-call glass page

- [`observe_glass()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass.md)
  : Observe every built-in glass control

- [`glass_scenes()`](https://ericrayanderson.github.io/shinyglass/reference/glass_scenes.md)
  : Named wallpaper scenes

- [`glass_scene_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_scene_input.md)
  : Scene picker for wallpaper packs

- [`observe_glass_scene()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_scene.md)
  :

  Observe
  [`glass_scene_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_scene_input.md)
  on the server

- [`glass_css_tokens()`](https://ericrayanderson.github.io/shinyglass/reference/glass_css_tokens.md)
  : Stable Liquid Glass CSS tokens

- [`glass_token_pack()`](https://ericrayanderson.github.io/shinyglass/reference/glass_token_pack.md)
  : Default CSS variable pack for a preset

- [`glass_add_tokens()`](https://ericrayanderson.github.io/shinyglass/reference/glass_add_tokens.md)
  : Override glass CSS tokens on a theme

- [`glass_flatten()`](https://ericrayanderson.github.io/shinyglass/reference/glass_flatten.md)
  : Flatten glass for print, PDF, and screenshots

## Plots and tables

Match ggplot2, plotly, gt, and DT to the glass light/dark pack.

- [`theme_glass()`](https://ericrayanderson.github.io/shinyglass/reference/theme_glass.md)
  : ggplot2 theme that follows glass light/dark ink

- [`plotly_glass()`](https://ericrayanderson.github.io/shinyglass/reference/plotly_glass.md)
  : plotly layout that matches glass chrome

- [`gt_theme_glass()`](https://ericrayanderson.github.io/shinyglass/reference/gt_theme_glass.md)
  : gt table options that match glass chrome

- [`glass_plot_colors()`](https://ericrayanderson.github.io/shinyglass/reference/glass_plot_colors.md)
  : Ink and grid colors for the current glass appearance

- [`glass_plot_surface_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_plot_surface_input.md)
  : Plot / table surface select

- [`observe_glass_plot_surface()`](https://ericrayanderson.github.io/shinyglass/reference/observe_glass_plot_surface.md)
  :

  Observe
  [`glass_plot_surface_input()`](https://ericrayanderson.github.io/shinyglass/reference/glass_plot_surface_input.md)
  on the server

- [`dt_options_glass()`](https://ericrayanderson.github.io/shinyglass/reference/dt_options_glass.md)
  : DT options that pair with glass plot surfaces
